## From answering questions to doing work

I've been experimenting with agentic AI and trying to understand what makes an AI agent different from a regular chatbot.

The simplest way I've found to think about it is that a chatbot primarily responds to prompts, while an agent can work through a task in multiple steps, use tools, inspect results, and decide what to do next.

That sounds straightforward until you start thinking about all the things that can go wrong.

## Giving an agent tools

One thing I'm interested in is how agents interact with their environment.

An agent might read a file, run a command, inspect an error, and then attempt a fix. Instead of manually guiding every step, I can give it a goal and let it work within a set of constraints.

But giving an AI access to tools also changes the risk.

There's a difference between an agent suggesting a command and an agent actually executing it. Permissions, isolation, and human approval become much more important when the system can take actions.

I'm learning that a useful agent isn't necessarily the one with the most freedom. It's the one that can accomplish something reliably without creating unnecessary problems.

## Learning through small experiments

I've been trying to approach agentic AI like any other engineering project: start with a small task, observe what happens, and make changes based on the results.

Rather than expecting an agent to solve everything perfectly, I want to understand where it succeeds, where it gets stuck, and how much supervision it needs.

It's also made me think more about evaluation. A convincing explanation isn't the same as a successful result. If an agent claims to have completed a task, I want some way to verify that it actually did.

## What's next?

I'm interested in exploring how agents can fit into a real development workflow, especially around repetitive tasks, research, and debugging.

For now, I'm treating this as an opportunity to learn how these systems behave rather than assuming every new AI tool is automatically useful.

The engineering challenge is just as interesting as the AI itself.
